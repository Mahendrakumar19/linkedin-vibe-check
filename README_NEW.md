# LinkedIn Vibe Check

A fun interactive quiz that generates your LinkedIn personality vibe! Take the quiz and share your results on social media.

## Features

- 🎯 Interactive quiz with randomized questions
- 🎨 Beautiful LinkedIn-themed UI with Tailwind CSS
- 📱 Responsive design for all devices
- 🎉 Confetti animation on results
- 📤 Share on Twitter, LinkedIn, WhatsApp, Facebook
- 📋 Copy to clipboard functionality

## Tech Stack

- **React 19** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS v4** - Styling
- **React Router** - Navigation
- **Canvas Confetti** - Animations
- **Vercel** - Deployment

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Build for production: `npm run build`
5. Preview production build: `npm run preview`
